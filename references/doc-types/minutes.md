# 議事録（minutes）

あわせて読む: domains/business.md
lint で外す規則: bold_label_list、excess_list、sentence_end_repetition

## 1. 普通な書き方（直さない）

- 項目に分けた構造と、体言止めの項目。
- 「**日時**: 10月1日」「**出席者**: 3名」のようなラベルと値。
- 同じ文末の連続（「〜しました。〜しました。」）と、伝聞の「〜とのこと」。
- 既定の読者の目安は expert（会議の出席者）。

## 2. それでも直すもの

- 発言者、作業した人、担当を引き受けた人の取り違え（domains/business.md 2章）。
- 元にない決定、ToDo、「決定なし」の記載。担当が書かれていないことを「担当未定」と決めること。

## 3. 長さと省略

- 話題の順と見出しの扱い（推敲では変えない。新しく作るときだけ話題ごとに整理してよい）は domains/business.md 3章。
- 体言止めの項目を文にのばさない。

## 4. 例（合成）

| 元 | 扱い |
|---|---|
| - 次回日程: 未定 | 残す（ラベルと値。原文の「未定」も残す） |
| 山田さんから進捗の報告がありました。資料の修正は佐藤さんが引き受けました。 | 残す（報告した人と引き受けた人を分けて書いている） |
