# PR説明（pr）

あわせて読む: domains/business.md
lint で外す規則: excess_list

## 1. 普通な書き方（直さない）

- 変更点と確認したことの箇条書き、チェックリスト、体言止めの項目（「期限切れのキャッシュを削除する処理を追加」）。
- テンプレートの見出し（概要、変更点、テスト、確認したこと）。見出しの数と順は変えない。
- 識別子が主語の文（`retry_limit` が再試行の上限を決める）。読者が expert か informed なら直さない（audience.md 7章）。
- 既定の読者の目安は expert（レビューする開発者）。

## 2. それでも直すもの

- 変更報告の述語の抜けと、実施済みと予定の取り違え（stance-and-endings.md 5章）。
- 確認したことと確認していないことを混ぜた文。確認していない動作を確認済みと書かない。
- 「- **改善点**: 〜を改善しました」のように、太字のラベルとコロンで説明の文を並べるだけの箇条書き（lint の bold_label_list はこの種類でも外さない）。

## 3. 長さと省略

- 1つの箇条に1つの変更を保つ。箇条書きを地の文にまとめない。
- 体言止めの項目を文にのばさない。

## 4. 例（合成）

| 元 | 扱い |
|---|---|
| - 期限切れのキャッシュを削除する処理を追加 | 残す（体言止めの変更点） |
| - **改善点**: 一覧の表示を改善しました | ラベルを外し、「一覧の表示を改善しました」のように述語まで書く。何をどう変えたかは、原文と資料にあるときだけ書く |
