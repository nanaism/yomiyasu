# 意味の薄くなりやすいカタカナ語の一覧（lint の katakana_term。yomiyasu_lint.py が読む）
# 実務の文書で、何を指すかが読み手に伝わりにくくなりやすいカタカナ語に印をつける。印は info で、直す合図ではない。
# 直すかは読み手と分野で決める（プロジェクト管理の文書の「マイルストーン」のように定着した使い方は残す）。直すときは、その語が
# 文の中で何を指しているかを原文から確かめて中身を書く。語を別の一語に替えるだけの直しはしない。
# 書き方: 1行に1語。長い語のカタカナの中にあっても当たる（ライティングソリューション）。カギ括弧の中、引用、コードは見ない。
# 空行と「#」で始まる行は読み飛ばす。足すときは行を足し、引くときは行の頭に「#」を付ける。
# このファイルがない、または読めない（UTF-8 でない）ときは、yomiyasu_lint.py の中の同じ一覧で動く。
# UTF-8 は BOM つきでもよい。一覧を変えると、前の検査記録は verify で tool_changed になる。
# プロジェクトで定着している語は、このファイルを変えずに、語の一覧の .yomiyasu-words/allow.txt に書いて外せる。
