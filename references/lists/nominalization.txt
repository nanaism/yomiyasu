# 名詞化の言い回しの一覧（文体の硬化の検査。yomiyasu_diff.py が読む）
# 推敲で、和語の短い言い回しが「〜が可能です」「〜を実施」のような名詞化した表現に置き換わり、文が硬くなったかを数えるのに使う。
# 書き方: 1行に1つ、「名前<TAB>正規表現」。名前は出力に出す短い形、正規表現は Python の re の書き方。
# 空行と「#」で始まる行は読み飛ばす。同じ位置で重なった当たりは1つに数える（「することが可能です」は1つ）。
# 足すときは行を足し、引くときは行の頭に「#」を付ける。このファイルがない、または読めない（正規表現の誤りなど）ときは、
# yomiyasu_diff.py の中の同じ一覧で動く（JSON の stiffness.list が "builtin" になる）。
# ファイルがあるのに読めないとき（UTF-8 でない、書き方や正規表現の誤り）は、diff の出力の「■ 文体の硬化」の節にそのことを
# 1行出す（JSON の stiffness.list_problem）。UTF-8 は BOM つきでもよい。一覧を変えると、前の検査記録は verify で tool_changed になる。
# 一覧は、和語の短い言い回しを名詞化した決まった形の11個（が可能、することが可能、の実施、を実施、を担保、を図る、
# に資する、につながる、の観点から、に関して、を行う）と「不可能」。「不可能」は、正しい推敲の組で増えないことを測ってから足した。
# 「に対して」「による」「における」などは、yomiyasu の正しい推敲でも増えるので入れていない。
