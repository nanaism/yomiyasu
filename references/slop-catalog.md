# AI生成文の不自然な語彙・構文カタログ

本カタログは、日本語LLM特有の不自然な語彙・構文パターンをまとめた辞書である。

---

## 1. AI偏愛動詞・比喩動詞

抽象的な事象や技術操作を、安易な比喩動詞で言い換える傾向を解体する。
なお、「骨が折れる」「手を焼く」「目から鱗が落ちる」「首を長くして待つ」のような、ふだんの日本語で定着した慣用句は、AIっぽい比喩として扱わず、そのまま残す。業務仕様でも、意味を取り違えるおそれがなければ残す。迷ったときの目安は、その言い方を、AIが広まる前の人の文章でもふつうに見かけるかどうかである。見かけるなら残す。

| AI偏愛動詞 | AI特有の用例 | 自然な人間表現への修正方針 |
|---|---|---|
| **効く / 効いてくる** | 「地味に効きます」「〜が効いてくる」 | 「目立たないながらも役に立つ」「じわじわ助けになる」（「地味に」の含みを残す） |
| **壊れる** | 「データが静かに壊れる」「設計が壊れる」 | データやシステムに対する「壊れる」はAI直訳・比喩のため「おかしくなる」「使えなくなる」のように、意味の広さが同じふだんの言葉にする。「データの整合性が失われる」「不整合が生じる」のように専門用語にするのは、元の文や前後から明らかに整合性の話だと分かるときだけに限定する（元の文の言い切りの強さは弱めない）。時計や機械、身体など文字どおりの物理的対象の「壊れる」はそのまま残す。 |
| **倒す** | 「〜側に倒す」「残さない側に倒す」 | 「〜を優先する」「〜の扱いに統一する」「除外する」 |
| **溶かす** | 「時間を溶かしました」 | 「思わず多くの時間がかかってしまった」「時間を費やしてしまった」（無駄にした・かかってしまった後悔の含みを残す） |
| **潰す** | 「1つずつ潰していく」 | 「1つずつ直す」「消す」「解決する」 |
| **踏み込む** | 「〜まで踏み込んで」 | 「詳しく調べる」「掘り下げる」 |
| **引き返す** | 「動かしながら引き返す」 | 「元の状態に戻す」 |
| **添える** | 「経路が代わりに添える」 | 「渡す」「つける」 |
| **収斂する** | 「その価格帯に収斂した」 | 「落ち着いた」「決まった」 |
| **沈黙する** | 「静かに沈黙する」 | 「何も通知が出ないまま終了する」「応答しない」（勝手に原因を狭めない） |
| **黙って** | 「黙って無視される」「黙って捨てられる」 | 「気づかないうちに無視される」「知らないうちに破棄される」（仕組みとしてエラーや通知が出ないことがはっきり分かる場合に限り「エラーを出さずに」「通知なく」とする） |

## 2. 英語直訳調・統語リーク

英語表現を直訳した結果生じる不自然な構文を平文化する。

| 英語の原表現 | AIの直訳日本語 | 自然な日本語 |
|---|---|---|
| *silently fail / ignored* | 「静かに壊れる」「黙って無視される」 | 「気づかないうちにデータがおかしくなる」「知らないうちに無視される」（データ等への「壊れる」は「おかしくなる」「使えなくなる」のように同等の広さの言葉にし、整合性の文脈であることが明らかな場合のみ「整合性が失われる」等とする。「静かに」「黙って」のぼかしは気づけない幅のまま直す。「通知なく」「エラーを出さずに」のように仕組みの話にするのは、元の文や前後から明らかな場合のみ） |
| *the moment ...* | 「〜した瞬間」「〜した瞬間に」 | 「〜するとすぐに」「〜した時点で」 |
| *single source of truth* | 「〜を正本にする」「〜の正本として」 | 原文、比較の基準、参照元等、文脈にある役割に合う語で書く。唯一の参照元と明示されている場合は、その限定を保つ。信頼性・唯一性・更新元という役割を新たに足さず、正式な文書を区別する「正本」は意味を保って残す。 |
| *point to / suggest* | 「〜を指している」「〜を示唆している」 | 「〜を表している」「〜と考えられる」「〜を意味する」 |
| *load-bearing* | 「耐力のある」「構造を支える」 | 「不可欠な」「根幹となる」「外せない」 |
| *it is not X, it is Y* | 「Xではなく、Yです」 | 単なる修辞でXを削っても通じる場合は「Yです」とする。Xと誤解されやすい点への反論や見方の切り替えを担っている場合は、否定を残して「Xではなく、Yです」と自然に整える（Aに加えてBなどに改変しない。「そのもの」等の余計な強調語は足さない）。 |
| *delve into* | 「〜に深く分け入る」「深掘りする」 | 「詳しく調べる」「具体的に見ていく」 |
| *em dash (— / ―)* | 「〜――とりわけ〜――は」 | 「〜をはじめとする〜は」（助詞で接続） |

## 3. 2026年急増語（Qiita 7万件調査に基づく分類）

AI普及以後の技術文書で急増した比喩・評価名詞を解体する。

| 分類 | 急増した語彙 | AI用例 | 修正方針（ふだん使う平易な言葉に開く） |
|---|---|---|---|
| **障害・失敗の比喩** | `事故` `混ざる` `落とし穴` `破綻` `実害` `素通り` | 「〜という事故」「落とし穴があります」 | `事故`→「思いがけない失敗・トラブル」、`混ざる`→「入り込む」、`落とし穴`→「見落としやすい点・気をつけたい点」、`破綻`→「うまくいかなくなる」、`実害`→「実際の困りごと」、`素通り`→「気づかず通る」 |
| **確認・検証の比喩** | `実測` `疑う` `照合` `突き合わせる` `断定` `取り違える` | 「実測では」「〜を取り違えると」 | `実測`→「実際に測った値」、`疑う`→「念のため見直す・確かめる」、`照合`→「照らし合わせる」、`突き合わせる`→「見比べる・比べる」、`断定`→「言い切る」、`取り違える`→「順序を間違える・勘違いする」 |
| **役割・位置の比喩** | `入口` `土台` `道具` `核心` `主役` `構図` `線引き` | 「〜の入口として」「〜するための土台」 | `入口`→「はじめの一歩・手始め」、`土台`→「基本・根っこ」、`道具`→「手段・やり方」、`核心`→「いちばん肝心なところ・大事な点」、`主役`→「中心」、`構図`→「全体の仕組み・関係」、`線引き`→「区切り・境界」 |
| **評価・結論の定型** | `既定` `別物` `定番` `要点` `定石` `桁違い` | 「既定では」「〜とは別物です」 | `既定`→「初めの設定・もともとの設定」、`別物`→「まったく違うもの」、`定番`→「よく使われるもの」、`要点`→「大事なところ」、`定石`→「いつものやり方・標準の進め方」、`桁違い`→「段違い・はるかに大きい」 |

## 4. 必殺技造語・体験の壮大化

個人のささやかな体験や日常的な技術判断を、重厚な熟語で大げさに語る傾向を排除する。

| 壮大化熟語群 | AIの典型的な不自然な記述 | 自然な表現 |
|---|---|---|
| `真理` `真実` `結末` `宿命` `運命` `境地` `極致` `究極` `虚飾` `虚像` `美学` `深淵` `禁欲的` `優美` `冷徹` `残酷` `凝縮` `結晶` | 日常の喧騒という虚飾を剥ぎ取った時、この道具の真実が見えてくる。 | 日々の忙しさから離れたとき、この道具の本当の良さが見えてくる。 |

個人の日常や業務エピソードに、元にない架空の固有名詞や普遍の教訓を不自然に付加しない方針をとる。

## 5. 質感を装う疑似具体語・ビジネスジャーゴン

一見プロっぽく見えるが、中身が何もない空虚なキーワードを排除する。

語だけで判定せず、何を指すかを原文と提供文脈から確かめる。本文だけでなく、変更理由や確認事項でも同じ基準を使う。

| 分類 | 対象語彙 | 是正ルール |
|---|---|---|
| **質感を装う語** | `手触り` `肌感` `肌感覚` `体温` `温度感` `熱量` `血の通った` `泥臭い` | 元の文や前後から分かる範囲で客観的な事実を書く。情報が足りない場合は作り話を足さず、同じ幅のふだんの言葉で書く。 |
| **認知を装う語** | `解像度`（解像度を上げる/高い） `腹落ち` `メンタルモデル` `文脈` | 何をどこまで調べたのか、元の文にある情報の範囲で客観的に書く。 |
| **評価を装う語** | `本質` `本質的` `地に足のついた` `等身大` | 「本質的なアプローチ」のような空疎な修飾語は削る。ただし、文の主題や論点そのものになっている語（「本質」「核心」など）を「目的」など別の概念へすり替えたり、勝手に動詞を足して文の働きを変えてはならない（「いちばん肝心な点」「大事なところ」など平易な言葉にするか、そのまま残す）。 |
| **未定義造語** | `意思決定OS` などの勝手な比喩命名 | ふだん使う平易な言葉や客観的な機能説明で書く（硬い漢語を並べない）。 |
| **役割を大げさに呼ぶ語** | ルールを指す `契約`、原文や比較の基準を指す `正本` | 「ルール」「方針」「原文」「比較の基準」「参照するファイル」等、実際の役割に合う語へ直す。取引・合意としての契約、正式な文書を区別する正本、定義された専門用語の意味は保つ。 |
| **指す内容が曖昧な名詞** | 手段や書き方を曖昧に呼ぶ `仕組み` | 何を行うか、何を指すかが分かる範囲で書く。実際の処理の関係や動作を説明する「仕組み」は残す。具体的に見せるために数値・体験・原因を足したり、評価や推量を消したりしない。 |

## 6. メタ宣言・時間稼ぎフィラー

読者の感情や理解度を先回りしてコントロールしようとする無駄な前置きや後置句を削除する。

| 分類 | 対象表現 | 是正ルール |
|---|---|---|
| **前置フィラー** | `重要なのは` `結論から言うと` `正直に言うと` `避けたいのは` `ここで注目すべきは` | 単なる前置きは削る。評価は述語へ移して保つ。理由・対比・結論や文の働きの切替を示す場合は、その関係を残す。比較から採用方針へ移る「結論として」などを、語だけで不要と判定しない。 |
| **後置ラベリング** | `〜というわけです` `〜に他なりません` `〜と言えるでしょう` `面白いのはここです` | 文末を客観的な事実記述で閉じる。元の文が推量（〜でしょう、〜と考えられます）の場合は、勝手に断定に上げず推量の強さを保つ。 |
| **定型クロージング** | `いかがでしたでしょうか` `ぜひ試してみてください` `〜の参考になれば幸いです` | 形式的呼びかけを削り、本文の自然な結びで終わる。 |
