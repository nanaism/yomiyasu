# エッセイ・小説（essay）

あわせて読む: domains/essay.md
lint で外す規則: なし

## 1. 普通な書き方（直さない）

- エッセイ: 書き手の語り、話し言葉、気持ちの語、体験の順。何を何に例えたかが読み取れる比喩は、字義どおりでなくても書き手の個性として残す。
- 小説の本文: 会話、読み取れる比喩、短い文の連続、ダッシュ、三点リーダー、語り手の主観、書き手が残した複数の読み（SKILL.md 4.1）。

## 2. それでも直すもの

- 主語と述語だけを取り出すと成り立たず、連想もできない比喩と、動作と主語が釣り合わない比喩。エッセイでも小説でも直す（目印は slop-catalog.md 8章）。直すときは前後の文から分かる様子だけで書き、分からなければ原文を残して「書き手に確かめたい点」で尋ねる。
- 係り方がずれて、文として通らないもの（4章の例）。
- エッセイの比喩動詞（slop-catalog.md 1章の表の動詞を比喩に使ったもの。「効く」「溶かす」の類。直し方は SKILL.md 4.4 の1行目と 4.5）。定着した言い方は残す。
- 小説でも、絵文字、チャット応答の名残、本文に残ったAIへの指示は直す。
- 直した案が、効き目をぼんやり述べる形や、slop-catalog.md 8章の目印の形（物や場所が「黙って〜している」など）になるなら、案を捨てて原文を残す。

## 3. 長さと省略

- 平均の文長の目安を使わず、書き手の文のリズムを残す。
- 小説の本文には、コピー調と装飾記号のダッシュの規則と、domains/essay.md の教訓や情緒語を見直す項目を当てない。lint はエッセイと小説を区別しないので、小説の本文の候補は確かめるだけにする。
- 比喩は前後の文と合わせて見る。あとの文で例えた理由を説明している比喩は残す。
- 比喩や語りを個性として残したときは、完了報告の最後（確認の記録の下）に1行、「エッセイと判断したので、文の個性を残しました」（小説なら「小説と判断したので、読み取れる比喩と語りを残しました」）と書く。直した箇所があっても書く。本文だけを返す指定では書かない。

## 4. 例（合成）

| 元 | 扱い |
|---|---|
| 寝つきが悪かった。散歩を始めてから、じわじわ効いてきた。（エッセイ） | 何がどう変わったかを書く（散歩を始めてから、少しずつ寝つきがよくなってきた）。前後から変わったことが分からなければ、定着した言い方にする |
| 面接の日程表は、季節を先取りする桜の花びらのように、机の端に貼られては剥がされた。（エッセイ） | 残す（何を何に例えたかが読み取れる。書き手の個性） |
| その声は、カウンターの硝子に触れて小さく曇った。（小説） | 残す（息で硝子が曇る様子と読める） |
| 白い鍵の上に指先の影が落ちた瞬間、家じゅうの時間が、ふっと息を吸い込んだ。（小説） | 直す（「時間が息を吸い込む」は何を言うかを連想できない）。前後の文から分かる様子で書き、分からなければ確かめる |
| あまりに温かくて、握った蹄払いの柄のほうが、先に力を失っていく。（小説） | 直す（あまりに温かくて、蹄払いの柄を握る手のほうが、先に力を失っていく） |
