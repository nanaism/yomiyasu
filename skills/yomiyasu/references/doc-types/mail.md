# メール・チャット（mail）

あわせて読む: domains/business.md
lint で外す規則: emoji_prohibited、meta_filler（返信と結びの5つの型だけ）

## 1. 普通な書き方（直さない）

社内外のメールと、Slack などのチャットの投稿。宛名、挨拶、署名、結びの言葉は、相手との関係を保つための書き方で、決まり文句として削らない。これらと敬語の度合いを残したことと、残した理由は、返答に書かない（SKILL.md 2章 Step 1 の1）。

- 宛名（〇〇様、〇〇さん、各位）、挨拶（お世話になっております、お疲れさまです）、結び（よろしくお願いいたします）、署名。slop-catalog.md 6章の「定型の結び」と「チャット応答の名残」を、相手への実際の返信と結びには当てない。lint もこの種類では、meta_filler のうち返信と結びの5つの型（「ご質問ありがとうございます」「必要なら次に〜します」「いかがでしたでしょうか」「ぜひ〜してみてください」「参考になれば幸いです」など）の候補を外す。meta_filler のほかの型（誇張や中身のない前置き）は外さない。
- 敬語の度合い。「〜いただけますでしょうか」を「〜してください」にせず、逆に「〜して」を「〜していただけますか」にもしない。頼みの強さと丁寧さは書き手が相手に合わせて選んだもの。書き手と読み手との関係を依頼で言われたときは、敬語は persona.md 7章の範囲で上げる（この項より先に当てる）。
- クッション言葉（お手数ですが、恐れ入りますが）。相手への配慮なので削らない。
- チャットの口語（〜かも、〜しときます、〜っす）。「です・ます」にそろえず、書き言葉にも直さない。
- 書き手が気持ちを表すために使った絵文字と「！」。lint はこの種類で emoji_prohibited を外す。
- 挨拶、頼み、結びの文末に「ます」が続くこと。lint の同じ文末が続く候補（sentence_end_repetition）が出ても、決まり文句の文末を書き換えて散らさない。

## 2. それでも直すもの

- 誤字、脱字、敬語の誤り。二重敬語や、「ご〜する」に「させていただく」を重ねた形（ご確認させていただきました）は、敬語の度合いを保ったまま直す（確認いたしました）。尊敬語と謙譲語の取り違え（資料を拝見してください → 資料をご覧ください）も直す。
- 何を頼んでいるのかが分からない文と、主語と述語が噛み合わない文。
- 1文に頼みごとが2つ以上混ざっていて、どちらに返事をすればよいか分からない文。頼みごとごとに文を分ける。分け方が1つに決まらないとき（期限がどちらの頼みに掛かるか分からないなど）は書き換えず、「書き手に確かめたい点」で尋ねる。
- 同じ詫びや礼が3回以上並ぶ所。このときだけ減らしてよい。1つは残し、「変えたところ」に書く。2回までは残す。
- 本文に残ったAIへの指示（slop-catalog.md 6章）。

## 3. 長さと省略

- 頼みごと、期限、数字、日時、金額、固有名詞、URL、メールアドレスは一字も変えない。期限を「中旬」「目安」のようにぼかさない。
- 短くしすぎない。挨拶やクッション言葉を削って用件だけにしない。
- diff の検査（Step 3 の run に `--doc-type mail` を付ける）の候補は、次のように見る。
  - 「■ 敬語の度合い」は mail のときだけ出る。1文あたりの敬語の数（いただく、くださる、申し上げる、存じます、させていただく）か、文末の「です・ます」の割合が、推敲の前後で20ポイント以上動いた文書の候補。敬語を外したり足したりしていたら、原文の言い方に戻す。ただし、依頼で書き手と読み手との関係を言われ、persona.md 7章の範囲で上げた所は戻さない。二重敬語を直した結果なら残し、「変えたところ」に書く。候補が出なくても、原文と読み比べる。「〜いただけますでしょうか」を「〜してください」にしても敬語の数は変わらず（「ください」も数える）、チャットの口語の文末（〜かも、〜しときます）は割合に入らないので、この検査では候補が出ない。
  - 「■ 動かしてはいけない値」の宛名の候補（田中様 → 田中さん）は、宛名を原文に戻す。期限や数字の変化は「■ 意味が変わる恐れ」の数値の候補に出る。
  - 「■ 勢い」の候補は、この種類では参考にならず、見直し候補のまま出る。チャットの「！」や絵文字を減らしていたら戻す。
- 宛先が社外なら、会話やファイルから補えるのは社外に出してよい事実だけ（`references/fact-recovery-details.md` 6章）。

## 4. 例（合成）

| 元 | 扱い |
|---|---|
| お手数ですが、10月20日までにご確認いただけますでしょうか。 | 残す（クッション言葉、敬語の度合い、日付） |
| それ明日でもいいかも、確認しときます | 残す（チャットの口語。「です・ます」にしない） |
| ご確認させていただきましたところ、問題ございませんでした。 | 直す（確認いたしましたところ、問題ございませんでした。）。敬語の度合いは変えない |
| 山本様、お世話になっております。先日お送りした見積もりは、いかがでしたでしょうか。 | 残す（宛名と挨拶。「いかがでしたでしょうか」は相手への実際の問い） |
| 見積書の送付と、打ち合わせの日程の調整を、金曜までにお願いできますか。 | 「金曜まで」が両方に掛かるか、日程の調整だけに掛かるかが決まらないので書き換えず、書き手に確かめる |
