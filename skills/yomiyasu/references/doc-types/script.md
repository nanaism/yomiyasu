# 台詞・脚本（script）

あわせて読む: domains/essay.md
lint で外す規則: bare_verb_chain、fragment_run、metaphor_label、sentence_end_repetition

## 1. 普通な書き方（直さない）

漫画のネーム、ドラマや映画のシナリオ、舞台やラジオの台本では、台詞は話し言葉で、地の文やト書きとは書き方が違う。

- 台詞として扱うのは、「」と『』の中、`名前「…」` の行、`名前：…` の行の中身。ナレーションの台詞も台詞に数える。
- ト書き（（ ）の中の動き、コマやシーンの説明、SE や M の音の指示）と地の文は、台詞ではない。書き手の指示として、短い文や体言止めのまま残す。
- 台詞の口調、言い回し、方言、言いよどみ（……、――）、語尾の「！」「？」は、書き手の人物の作り方として残す。
- 台詞の中の短い文の重ね（「見た。見たけど、忘れ物」）、同じ語尾の続き、主語を書かない言い方は直さない（lint の fragment_run と sentence_end_repetition は外す）。
- 題、話数、コマとページの番号、場面の見出しは変えない。

## 2. それでも直すもの

- 台詞の最後の「。」。AI が書いた台詞は、ほとんどが「。」で終わる。lint の dialogue_period の印（台詞の数と、「。」で終わる割合）がついたら、台詞の最後の「。」だけを外す。台詞の中の文と文の間の「。」、ト書きと地の文の「。」は残す。印がつかない台本（「。」で終わる台詞が半分に満たないか、台詞が10個に満たない）は、書き手が選んで打っていると見て、台詞の句点を外さない。
- 依頼か本文で句点を打つ書き方を指定されているとき（音読の練習用、出版社の表記の決まりなど）は、台詞の最後の「。」も外さない。
- 台詞の外の誤字と脱字、ト書きで誰が何をするかが読めない文。台詞の中は、誤字と分かるものだけを直す。
- 絵文字、チャット応答の名残、本文に残った AI への指示。

## 3. 長さと省略

- 台詞の数と順、話し手の名前、コマとシーンの区切りは変えない。台詞をまとめたり分けたりしない。
- 台詞の言い回しを地の文の決まり（主語の補い、文の長さ、比喩の具体化）で直さない。
- ペルソナで本文を変えない（敬語を上げない、主語を補わない）。ペルソナの知らせも出さない（persona.md 8章）。
- 小説や公用文でカギ括弧の中に句点を打つのは誤りではない。script と決めた文書のほかでは、台詞の句点を外さない。
- 会話やファイルからは事実を補わず、事実の問いも出さない（`references/fact-recovery-details.md` 6章）。

## 4. 例（合成）

| 元 | 扱い |
|---|---|
| 千夏「今日の練習、もう終わりにしようよ。」 | 最後の「。」だけを外す（千夏「今日の練習、もう終わりにしようよ」） |
| 店長「棚は全部拭いた。あとは床だけだ。」 | 最後の「。」だけを外し、間の「。」は残す（店長「棚は全部拭いた。あとは床だけだ」） |
| 浩二：待てよ、まだ話は終わってない | 残す（「。」がない。口調と短い言い方も残す） |
| （千夏、窓を開ける。外は雨。） | 残す（ト書きの「。」と体言止めは直さない） |
| 少年「やった！」 | 残す（「！」で終わる台詞は変えない） |
| ※台詞の句点は、読み聞かせの練習のために打っています。 | 指定として読み、台詞の最後の「。」を外さない |
