# 提案書（proposal）

あわせて読む: domains/business.md
lint で外す規則: なし

## 1. 普通な書き方（直さない）

- 結論や提案を先に置いた構成。
- 論点や費用の箇条書き。
- 「ご判断ください」「ご承認をお願いします」のように判断を求める文。

## 2. それでも直すもの

- 効果の見込みを強める直しと、元にない効果を足すこと（業務効率が大きく向上します、など）。
- 判断を求める強さの変化。依頼、相談、提案、決定を取り違えない（domains/business.md 2章）。
- 読み手（上司、決裁者）が決める事柄を決まった形で書いた文は、書き手と読み手を指定されたとき知らせる。書き手が決められる立場（リーダーからチームへ）の文と、案と分かる文は知らせない（persona.md 5章）。

## 3. 長さと省略

- 推敲では構成を組み替えない。結論を前に出す直しもしない。
- 費用、期間、条件の数値と、その掛かる範囲を保つ。

## 4. 例（合成）

| 元 | 扱い |
|---|---|
| 導入により、問い合わせ対応が楽になる見込みです。 | 「見込みです」の確度を保つ。「楽になります」と言い切らない |
| 来週の定例でご判断ください。 | 残す（判断を求める依頼の文） |
