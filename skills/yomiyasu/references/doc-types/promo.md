# 紹介記事・宣伝文（promo）

あわせて読む: domains/essay.md か domains/business.md（個人の記事は essay.md、店や会社の宣伝文は business.md）
lint で外す規則: emoji_prohibited、fragment_run

## 1. 普通な書き方（直さない）

商品、お店、場所、サービス、作品を勧める記事と宣伝文では、書き手の勢いが記事の魅力そのものになる。技術文書やヘルプと同じ直し方をすると、その魅力を削る。

- 「！」: 消さず、読点にも変えない。同じ段落に3つ以上並んでも減らさない。
- 見出しのキャッチコピー: 短い項目名にする直し（SKILL.md「案内用の見出し」「コピー調の抑制」）を当てない。言い回しを本文へ移しても、見出しで読者を引きつける働きは戻らない。見出しとして書かれた番号つき項目の行（1. 昭和から愛される…）と太字だけの行も同じに扱う（`--doc-type promo` の diff の勢いの検査も、これらを見出しに数える。箇条書きの太字の行（- **…**）は数えないので、縮めていないかを読み比べる）。
- 本文で評価の語を短く重ねる型（安い。うまい。早い。）も勢いとして残す。対象と評価を1文につなぐ直し（SKILL.md「コピー調の抑制」）を当てない。
- 勢いのある語（パンチ、大活躍、最強、イチオシ、抜群）: 「力強い風味」「重宝」のような落ち着いた言い方に置き換えない（slop-catalog.md 7章の硬い漢語と誇張語の行を当てない）。
- 強める語（本当に、ぜひ、ずらりと）: 気持ちや量の強さを表すので削らない。「ぜひ〜してみてください」も書き手の実際の勧めとして残す（lint の meta_filler の候補は確かめるだけにする）。
- 同じ褒め言葉の繰り返し（1段落に「絶品」が3回）: 勢いとして残す。並んだ対象を1文にまとめず、回数を減らさず、ほかの語にも置き換えない。元にない褒め言葉は足さない。
- domains/essay.md の「過剰な修飾語を削る」と、domains/business.md の「過剰な装飾を減らす」「自然で客観的な表現」は、勢いのある語と強める語に当てない。
- 絵文字: 書き手が気持ちや勢いを表すために使ったものは残す。
- 「〇選」「おすすめ」の見出し、ランキングや一覧の形、価格や購入先の案内。

## 2. それでも直すもの

勢いを残すことは、読みにくさを残す理由にならない。

- 誤字と脱字。表記の揺れをそろえるのは、ほかの種類と同じく表記の校正に任せる（SKILL.md「用途と表記の扱い」）。
- 主語と述語が噛み合わない文、係り先の分からない文。見出しも、事実の誤りや主述のずれがあるときだけ直す。
- 根拠のない誇張が事実のように書かれている所（「県内でいちばん売れている」「誰もが絶賛」）。yomiyasu は事実を確かめられないので、書き換えずに「書き手に確かめたい点」で根拠を尋ねる（本文を確定するのに要る確認として、確かめたい点の3点の中に数える）。

## 3. 長さと省略

- 見出しの数と順、一覧の項目の数と順、価格、商品名、店名、購入先は変えない。
- ペルソナで本文を変えない（敬語を上げない、主語を補わない）。ペルソナの知らせ（知りえない事情、断定、合わない言い方）も出さない（persona.md 8章）。
- 1章の勢いのある書き方（見出しの言い回し、「！」、勢いのある語など）を残したときは、本文とは別に、利用者への補足として完了報告の最後（確認の記録の下）に1行、「紹介記事・宣伝文と判断したので、勢いのある書き方を残しました」と書く（doc-types/essay.md 3章と同じ形）。直した箇所があっても書く。本文だけを返す指定のときは書かない。
- 会話やファイルからは事実を補わない。新しい問いは出さず、2章の根拠のない誇張だけを尋ねる。文脈に中身がある穴は「補える事実（本文には入れていません）」として報告に書く（`references/fact-recovery-details.md` 6章）。

## 4. 例（合成）

| 元 | 扱い |
|---|---|
| 港町のスーパーで探す最強のお土産！安くて美味いご当地ラーメン4選 | 残す。「最強のお土産、」のように「！」を読点に変えない |
| 1. 昭和から愛される港町のソウルフード「しおかぜラーメン」（なぎさ製麺） | 残す。「1. しおかぜラーメン（なぎさ製麺）」に縮めない |
| 2. 焦がしニンニク油が香る本格派「灯台とんこつラーメン」（なぎさ製麺） | 残す。「2. 灯台とんこつラーメン（なぎさ製麺）」に縮めない |
| 焦がしニンニク油のパンチを自宅で味わうなら | 残す。「力強い風味」にしない |
| 自宅用にも配り用にも大活躍するおすすめ銘柄 | 残す。「重宝する」にしない |
| 港町の駅前にある食堂の日替わり定食。安い。うまい。早い。 | 残す。「この定食は安く、うまく、早い。」のように1文につながない |
| スープは濃厚！麺はもちもち！しおかぜラーメン、本当におすすめです！ | 残す。同じ段落に「！」が3つ以上並んでも減らさず、読点にも変えない |
| この麺は絶品です。スープも絶品で、具も絶品です。 | 残す。「この麺もスープも具も絶品です。」のように1文にまとめず、「絶品」を減らさない |
| どこの店より安い、県内でいちばん売れているお土産です！ | 本文は変えず、「書き手に確かめたい点」で「どこの店より安い」「いちばん売れている」の根拠を尋ねる |
