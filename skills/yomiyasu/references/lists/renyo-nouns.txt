# 他動詞を1語だけ名詞にした語の一覧（lint の renyo_noun。yomiyasu_lint.py が読む）
# 「結果の確かめ」「案の比べ」のように、他動詞の連用形を1語だけ名詞にした語を「の」で受ける形に印をつける。印は info で、直す合図ではない。
# この形の語は名詞としての自立性が弱く、目的語を「の」で受ける形では使いにくい。漢語を避けて和語で書くと出やすい（確認→確かめ、比較→比べ）。
# 直すときは、目的語と動詞の文に戻すか（結果を確かめる）、定着した漢語の名詞にする（結果の確認）。ほかの和語の連用形名詞に替えるだけで済ませない。
# 名詞とくっつけた複合語（資金集め、手直し）、複合動詞から来た語（見直し、組み合わせ）、「お」「ご」を付けた形（お選び）は、
# 「の」のすぐあとにこの一覧の語が来ないので当たらない。
# 別の意味で名詞として定着した語は入れていない（住民票の写し、合格の知らせ、詰めが甘い、法律の定め、顧客の求め、欠勤の届け、
# 相場の上げ、駅までの送り、漢字の書き、情勢の読み、警察の調べ、質問の答え、災害への備え など）。
# 書き方: 1行に1語か、「語<TAB>外す後ろの文字列」（| で区切って複数）。後ろがその文字列のときは印をつけない（「生活の足しになる」「試しに」の「に」、「育ての親」の「の親」）。
# カギ括弧の中、引用、コードは見ない。空行と「#」で始まる行は読み飛ばす。足すときは行を足し、引くときは行の頭に「#」を付ける。
# このファイルがない、または読めない（UTF-8 でない）ときは、yomiyasu_lint.py の中の同じ一覧で動く。
# UTF-8 は BOM つきでもよい。一覧を変えると、前の検査記録は verify で tool_changed になる。
# プロジェクトで定着している語は、このファイルを変えずに、語の一覧の .yomiyasu-words/allow.txt に語だけ（「の」を付けずに、確かめ）書いて外せる。
