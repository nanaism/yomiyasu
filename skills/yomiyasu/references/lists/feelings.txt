# 気持ちの語の一覧（元の文書にない気持ちの語を足した推敲を、意味が変わる恐れ feeling として出す。yomiyasu_diff.py が読む）
# 推敲後の変わった文に、元の文書のどこにもない気持ちの語（ほっとした、安堵した、うれしかった など）が出たら候補にする。
# 書き方: 1行に1つ、「名前<TAB>正規表現」。1行が語の家族（嬉し・うれし など）で、元の文書に同じ家族の語があれば出さない。
# 3つ目の欄を置いてもよい（「名前<TAB>正規表現<TAB>原文の言い方の正規表現」）。原文にこの言い方があれば、その家族の気持ちは
# 原文にあるとみなして出さない（原文の「お詫び申し上げます」を「申し訳ありません」に、「ありがとう」を「感謝します」に言い換えた推敲）。
# 気持ちでない決まった言い方は、正規表現の中で除く（心配はありません、条件を満足する、売上が落ち込む）。
# 空行と「#」で始まる行は読み飛ばす。足すときは行を足し、引くときは行頭に「#」を付ける。
# このファイルがない、または読めないときは、yomiyasu_diff.py の中の同じ一覧で動く（JSON の feeling.list が "builtin" になる）。
